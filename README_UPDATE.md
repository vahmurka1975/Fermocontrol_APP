УСТАНОВКА
1. Сохраните свои локальные изменения коммитом. Если работаете на другом компьютере,
   сначала получите актуальный main командой git pull --ff-only.
2. Распакуйте архив во временную папку.
3. Скопируйте папку app из архива в C:\AndroidStudioProjects\Fermocontrol.
   Согласитесь на объединение папок и замену MainActivity.kt и strings.xml.
   Не удаляйте существующую папку app: в архиве только изменённые и новые файлы,
   а не полный проект. README_UPDATE.md можно сохранить в корне проекта.
4. В терминале Android Studio из корня проекта выполните:
   .\gradlew.bat testDebugUnitTest assembleDebug
5. После BUILD SUCCESSFUL запустите приложение на телефоне или эмуляторе через Run.
6. После проверки:
   git add .
   git commit -m "Add products screen, weighing journal and archive"
   git push

ФУНКЦИИ
— Пустой начальный экран без вымышленных продуктов.
— Добавление продукта: название, основа, оболочка, несколько специй, начальный вес,
  индивидуальная цель по потере веса. Допускается десятичная запятая или точка.
— Автоматический первый свободный номер среди активных продуктов.
— Карточка: номер, вес, потеря веса, цель и время добавления.
— Взвешивание с автоматическим временем сохранения.
— Капсулы запаха, поверхности, цвета и плотности; свободная заметка.
— Просмотр истории; изменение исходных параметров и старых взвешиваний не предусмотрено.
— Извлечение после подтверждения: перенос в архив с сохранением истории и освобождением
  активного номера. Архивная карточка хранит бывший номер для справки, а не резервирует его.
— Локальное атомарное сохранение JSON во внутреннем каталоге приложения.
  Данные сохраняются после закрытия приложения, но исчезнут при очистке его данных.
  GitHub хранит исходники, а не пользовательский журнал. Системное резервное копирование
  зависит от настроек Android; отдельного экспорта и облачной синхронизации пока нет.
— При ошибке чтения данных запись блокируется, чтобы не затереть журнал пустым списком.

ПРОВЕРКА НА УСТРОЙСТВЕ
1. Добавьте два продукта: ожидаются №1 и №2.
2. Взвесьте №1 и выберите наблюдения. Проверьте журнал и автоматическое время.
3. Извлеките №1. Он должен перейти в архив вместе с журналом.
4. Добавьте третий продукт. Он должен получить освободившийся №1.
5. Закройте и снова откройте приложение. Данные должны остаться.
6. Поверните телефон, откройте клавиатуру в формах, проверьте прокрутку.

ОГРАНИЧЕНИЯ ЭТАПА
Это исходники обновления, не APK и не полный Android-проект. Room, напоминания,
фотографии, датчики температуры/влажности и экспорт ещё не добавлены.
JSON — временное простое хранилище для первого этапа. При переходе на Room понадобится
перенос существующих данных, а не их удаление.
Дата и время используют часы телефона и отображаются в его текущем часовом поясе.
Потеря веса и внешний вид не подтверждают безопасность пищи; выбор оболочки и других
параметров в интерфейсе не означает одобрение рецепта. В приложении нет проверенных
технологических режимов для разных видов продуктов.
